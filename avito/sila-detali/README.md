# Авито «Сила Детали»: фид автозагрузки

`feed.xml` — объявления, которые тред «Авито: кабинет Сила детали» выкладывает через автозагрузку Авито (новые позиции из остатков 1С и пересобранные объявления, по 30 в день). `slides/` — слайды о магазинах и подсказки для добивки фото до 5–8.

Ветка `avito-sila` отдельная, main не трогается. Фид читает Авито по адресу
https://raw.githubusercontent.com/79608844988t-lgtm/setra-ozon-media/avito-sila/avito/sila-detali/feed.xml
