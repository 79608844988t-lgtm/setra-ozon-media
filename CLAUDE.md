# setra-ozon-media — правила для Claude

Фото и инфографика карточек Ozon магазина «Сила детали». Ozon забирает файлы по прямым ссылкам
raw.githubusercontent.com/79608844988t-lgtm/setra-ozon-media/main/photo/…, поэтому:

- Отвечать по-русски, кратко, без жаргона (владелец — Артем Мазлов, не программист).
- Не удалять, не переименовывать и не перемещать уже опубликованные файлы: на них ссылаются карточки Ozon.
- Не переписывать историю, не делать репозиторий приватным — ссылки перестанут открываться.
- Репозиторий большой (~3,3–3,8 ГБ, у GitHub жёсткий порог около 5 ГБ). Клонировать с `--depth 1`,
  не добавлять видео и исходники крупнее нескольких МБ.
- Пути: `photo/infographics/<offer_id>/0N.jpg` (инфографика «Сила детали»), `photo/new/`, `photo/avito/`, `video/`.
  В именах бывают пробелы и кириллица — в ссылках кодировать.
- Генератор волн инфографики (u5-*.json) живёт на Mac владельца, не в git.
- План переезда в хранилище Timeweb S3 — `docs/s3-plan.md`. До решения владельца новые волны по-прежнему сюда.
